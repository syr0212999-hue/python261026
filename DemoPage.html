웹 프론트엔드 기초

HTML5 · CSS3 · JavaScript를 한 페이지에서 학습해 보세요.

HTML5 CSS3 JavaScript

1. HTML5: 웹의 구조

HTML은 제목, 문단, 목록, 링크, 이미지와 같은 웹 요소의 의미와 구조를 표현합니다.

<header>

페이지 또는 영역의 머리글을 나타냅니다.

<main>

페이지의 주요 내용을 나타냅니다.

<footer>

페이지 또는 영역의 바닥글을 나타냅니다.

2. CSS3: 웹의 디자인

CSS는 색상, 크기, 여백, 배치와 화면 크기에 따른 반응형 디자인을 담당합니다.

  • 색상: color, background
  • 크기와 여백: width, margin, padding
  • 배치: Flexbox와 Grid
  • 반응형: @media 규칙

3. JavaScript: 웹의 동작

JavaScript로 버튼 클릭, 입력값 처리, 화면 변경과 같은 동작을 구현할 수 있습니다.
