# Todo List 웹사이트 PRD

## 1. 제품 개요

HTML5, CSS3, JavaScript만 사용하여 브라우저에서 사용할 수 있는 Todo List 웹사이트를 만든다. 별도의 프레임워크나 백엔드 서버 없이 정적 페이지로 동작한다.

## 2. 목표

- 사용자가 할 일을 빠르게 등록할 수 있다.
- 할 일을 완료 상태로 관리할 수 있다.
- 불필요한 할 일을 삭제할 수 있다.
- 새로고침 후에도 할 일 목록을 유지할 수 있다.

## 3. 주요 사용자

- 개인 일정과 소규모 업무를 관리하는 일반 사용자
- 별도 계정 가입 없이 간단한 일정 관리 도구를 원하는 사용자

## 4. 핵심 기능

### 4.1 할 일 추가

- 텍스트 입력창에 할 일을 입력한다.
- 추가 버튼 또는 Enter 키로 할 일을 등록한다.
- 빈 문자열은 등록할 수 없다.
- 등록 시 목록 상단 또는 하단 중 UX 문서에 정의된 위치에 추가된다.

### 4.2 할 일 완료

- 할 일별 체크박스를 클릭하여 완료/미완료 상태를 변경한다.
- 완료된 할 일은 취소선과 흐린 색상으로 표시한다.

### 4.3 할 일 삭제

- 할 일별 삭제 버튼으로 항목을 삭제한다.
- 삭제 전 별도의 확인 절차는 필수로 하지 않는다.

### 4.4 목록 필터

- 전체, 진행 중, 완료됨 필터를 제공한다.
- 필터 변경 시 해당 상태의 할 일만 표시한다.

### 4.5 데이터 저장

- 할 일 목록과 완료 상태를 `localStorage`에 저장한다.
- 페이지를 새로고침하거나 다시 열어도 저장된 목록을 불러온다.

### 4.6 전체 삭제

- 완료된 항목만 삭제하는 기능을 선택적으로 제공한다.
- 동작 범위와 표시 조건은 구현 단계에서 확정한다.

## 5. 화면 구성

- 페이지 제목
- 할 일 입력 영역
- 추가 버튼
- 전체/진행 중/완료됨 필터 영역
- 할 일 목록
- 비어 있을 때 안내 메시지

## 6. 비기능 요구사항

- 데스크톱과 모바일 화면 모두에서 사용 가능해야 한다.
- 최신 Chrome, Edge, Firefox 및 Safari에서 기본 동작을 지원한다.
- JavaScript 오류 없이 입력, 완료, 삭제, 필터, 저장 기능을 제공한다.
- 키보드만으로도 핵심 기능을 사용할 수 있어야 한다.
- 로딩 외부 라이브러리를 사용하지 않는다.

## 7. 성공 기준

- 할 일을 추가, 완료, 삭제할 수 있다.
- 새로고침 후 목록이 유지된다.
- 필터가 올바르게 동작한다.
- 모바일 화면에서 레이아웃이 깨지지 않는다.
